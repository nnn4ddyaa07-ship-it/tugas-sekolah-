Algoritma

  1. Mulai.
  2. Buka halaman Data Siswa.
  3. Isi data siswa.
  4. Klik tombol Tambah/Simpan.
  5. Sistem memeriksa kelengkapan data.
  6. Jika lengkap, data ditambahkan ke tabel.
  7. Jika tidak lengkap, tampilkan pesan kesalahan.
  8. Selesai.

Pseudocode

BEGIN
  Tampilkan halaman Data Siswa
  INPUT nama
  INPUT NIS
  INPUT kelas
  INPUT jurusan

  IF data lengkap THEN
      Tambahkan data ke tabel
      Tampilkan "Data berhasil ditambahkan"
  ELSE
      Tampilkan "Data harus diisi lengkap"
  END IF
END
